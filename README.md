

#  To-Do List Android App

A simple and user-friendly **To-Do List Android application** built using **Kotlin, Java, and XML**.
This app helps users add, view, and manage daily tasks efficiently with a clean UI.

---

##  Features

*  Add new tasks easily
* Display tasks in a ListView
*  Local data storage using file handling
*  Simple and clean UI design
*  Fast and lightweight application

---

##  Technologies Used

* **Kotlin** – Main activity logic
* **Java** – Helper classes & file handling
* **XML** – UI design and layouts
* **Android Studio** – Development environment

##  How It Works

1. User enters a task in the input field
2. Clicks the **Add** button
3. Task is saved locally using file storage
4. Tasks are displayed in a **ListView**

---

##  Getting Started

### Prerequisites

* Android Studio (latest version recommended)
* Android SDK
* Minimum SDK: As defined in the project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/muski630346/To-Do-List-Android-App.git
   ```
2. Open the project in **Android Studio**
3. Sync Gradle files
4. Run the app on an emulator or physical device
